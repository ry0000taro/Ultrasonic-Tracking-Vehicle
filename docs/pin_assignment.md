> v0.1 は講義用の TE-01 基板のピン（LED=PB12〜15、スイッチ=PC10〜13、エンコーダ=PA8/PA9 など）を前提にしていた。

## 0. ピン変更（2026-11-20 確定）

回路図（1 章・2 章の表）から、次のピンに変更した。**ファームウェアと 3 章・6 章は、この変更後のピンが正**。

| 用途 | 旧ピン（回路図） | 新ピン（確定） | 備考 |
|---|---|---|---|
| エンコーダ1 B相 | PC8 | **PA8** | TIM1_CH1 |
| エンコーダ1 A相 | PC9 | **PA9** | TIM1_CH2（A相が CH2 になる。回転方向と符号が逆なら入れ替える） |
| モータ2 IN1 | PB4 | **PA1** | TIM2_CH2（AF1） |
| モータ2 IN2 | PB5 | **PA0** | TIM2_CH1（AF1） |
| 液晶 RESET | PA8 | **PA10** | GPIO出力 |
| 液晶 DC/RS | PA9 | **PB14** | GPIO出力 |
| ブザー | PA0 | **PB10** | GPIO出力。PA0 をモータ2 に使うため移動 |

- 変更の理由: Encoder1 を TIM1 のハードウェアエンコーダにして取りこぼしと CPU 負荷をなくす。Motor2 と Encoder1 を、講義用 TE-01 基板のコネクタ（Motor2=PA0/PA1、Encoder1=PA8/PA9）でそのまま動作確認できるようにする。
- **基板側の対応が必要**: 1 章・2 章の表は変更前の回路図の内容。上の表のとおり、基板の配線（またはジャンパ線）を変更する。
- PB14 は基板上で LED D1 につながっている。液晶 DC を出力すると D1 が薄く点滅する（動作に支障はない）。
- 空いたピン: PC8, PC9, PB4, PB5。
- **ファームウェアの正は `Core/Inc/main.h` の `*_Pin` 定義（`.ioc` から生成）**。

## 2. ピンの競合（2つの資料で同じピンを使用）

> ⚠️ 旧ピン前提の表。PB14（LED D1）は液晶 DC に使うため、補助LEDには使えない（0 章）。

| ピン | 基板設計 | 電気系設計 | 本案での優先 |
|---|---|---|---|
| PC0〜PC3 | A/D1〜4 | 超音波 Echo | **超音波Echo**（A/Dは使わない） |
| PC10 / PC11 / PC12 | S4 / S1 / S2 | 超音波 Trig U1 / U2 / U3 | **超音波Trig**（S1, S2, S4 は使わない） |
| PB12 / PB13 / PB15 | LED D2 / D3 / D4 | 液晶 CS / SCK / SDI | **液晶**（LED D2〜D4 は使わない） |

理由: 超音波センサと状態表示は要件書の Must 機能（FR-01, FR-08）で、基板のスイッチ・LED・A/Dは代替が利く。

**注意（実機）**: 競合ピンは基板上で両方に配線されている。ソフトでTrigを出力にしているPC10〜PC12は、**タクトスイッチ S1, S2, S4 を押すとピンを直接GNDに短絡する**。押さない運用にするか、スイッチをはずす。同様に PB12/PB13/PB15 のLEDは液晶のSPI信号で点滅する（表示に問題はないが、LEDとしては使えない）。

## 4. 設計上の問題点と対処

1. **モータ1とモータ2のタイマ**。モータ1は PA6/PA7 の TIM13/TIM14（AF9）。モータ2 は、当初 PB4/PB5 の TIM3 で、PA6/PA7 の TIM3 と同じ ch を取り合うため、モータ1を TIM13/TIM14 に逃がしていた。0 章の変更でモータ2 は PA1/PA0 の TIM2（AF1）になり、取り合いはなくなった（モータ1 は TIM13/TIM14 のまま）。
2. **エンコーダ1は PA9/PA8 の TIM1 でハードウェアエンコーダにする**（0 章）。旧案の PC8/PC9 は TIM8_CH3/CH4 でエンコーダモードにできず、EXTI のソフト4逓倍が必要だった。PA8/PA9 は TIM1_CH1/CH2（A相が CH2、B相が CH1）なので、エンコーダ2（TIM4）と同じ形で扱える。
3. **Echo（PC0〜PC3）にもタイマchがない**。→ EXTI の両エッジで TIM5 の値を読み、立ち上がり〜立ち下がりの差でパルス幅を求める。逐次発火のため同時に1本しか来ず、これで足りる。EXTI の優先度は高めにする。
4. **スイッチとLEDの大半が使えなくなる**（2章）。ユーザー操作は PC13 だけになる（補助LED D1 の PB14 は液晶 DC に使うため使えない。0 章）。足りなければ、空きピン（PC8, PC9, PB4, PB5 など。回路図で未使用を確認すること）に外付けする。
5. **PA8/PA9**: 変更前は液晶の RESET/DC だった。0 章の変更でエンコーダ1 に使う。液晶 RESET/DC は PA10/PB14 に移す。

## 5. 未確認事項

- TIM13/TIM14 を PA6/PA7 に割り当てるAF（AF9）は、STM32F446 のデータシートで最終確認する。
- Notion の表で「電気系設計側では信号ごとの対応までは確認していない」とされている PA6/PA7/PB4/PB5 と PC8/PC9/PB6/PB7 は、**電気系設計の基板にも同名ピンがある**。同じ配線なのか別かを回路図で確認する。
- エンコーダの A相/B相の割り当て（PA9=A, PA8=B）が実際の回転方向と合っているか、実機で確認する。
- ブザー（UDB-05LFPN）がアクティブかパッシブか、データシートで確認する。
- ERR-03（バッテリー電圧監視）に使えるA/Dピンがなくなった（PC0〜3 は超音波Echo）。ADC対応の空きピン（PA1, PA4, PB0, PB1, PC5 など）に分圧回路を追加する必要がある。
- 液晶（MSP2807）の駆動ICと表示ライブラリ。
- 3.3Vの供給能力（A/D、I2C、変換モジュール、モータドライバ、液晶LEDが共用）。
