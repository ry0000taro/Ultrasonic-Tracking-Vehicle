## 2. ピンの競合（2つの資料で同じピンを使用）

| ピン | 基板設計 | 電気系設計 | 本案での優先 |
|---|---|---|---|
| PC0〜PC3 | A/D1〜4 | 超音波 Echo | **超音波Echo**（A/Dは使わない） |
| PC10 / PC11 / PC12 | S4 / S1 / S2 | 超音波 Trig U1 / U2 / U3 | **超音波Trig**（S1, S2, S4 は使わない） |
| PB12 / PB13 / PB15 | LED D2 / D3 / D4 | 液晶 CS / SCK / SDI | **液晶**（LED D2〜D4 は使わない） |

理由: 超音波センサと状態表示は要件書の Must 機能（FR-01, FR-08）で、基板のスイッチ・LED・A/Dは代替が利く。

**注意（実機）**: 競合ピンは基板上で両方に配線されている。ソフトでTrigを出力にしているPC10〜PC12は、**タクトスイッチ S1, S2, S4 を押すとピンを直接GNDに短絡する**。押さない運用にするか、スイッチをはずす。同様に PB12/PB13/PB15 のLEDは液晶のSPI信号で点滅する（表示に問題はないが、LEDとしては使えない）。

## 4. 設計上の問題点と対処

1. **モータ1とモータ2が TIM3 の同じchを取り合う**。PA6/PA7 は TIM3_CH1/CH2、PB4/PB5 も TIM3_CH1/CH2 で、同一タイマでは片方のピンしか使えない。→ モータ1を TIM13/TIM14（PA6=TIM13_CH1, PA7=TIM14_CH1, ともにAF9）に振り分けて回避。基板の変更は不要。
2. **エンコーダ1（PC8/PC9）は HW エンコーダモードにできない**。PC8/PC9 は TIM8_CH3/CH4 で、エンコーダモードは CH1/CH2 の組が必要。→ EXTI の両エッジ割り込みで A/B のグレイコードを読み、ソフトで4逓倍する。最大 0.5 m/s ではパルス周波数は低く、負荷は小さい見込み（エンコーダ分解能は未確認なので、実機で確認する）。
3. **Echo（PC0〜PC3）にもタイマchがない**。→ EXTI の両エッジで TIM5 の値を読み、立ち上がり〜立ち下がりの差でパルス幅を求める。逐次発火のため同時に1本しか来ず、これで足りる。EXTI の優先度は高めにする。
4. **スイッチとLEDの大半が使えなくなる**（2章）。ユーザー操作は PC13 だけ、補助LEDは PB14 だけになる。足りなければ、競合しない空きピン（PA10, PB10 など。回路図で未使用を確認すること）に外付けする。
5. **PA8/PA9**: 基板設計の回路図ではネットラベルのみ（部品なし）。電気系設計では液晶の RESET/DC として使うので問題ない。

## 5. 未確認事項

- TIM13/TIM14 を PA6/PA7 に割り当てるAF（AF9）は、STM32F446 のデータシートで最終確認する。
- Notion の表で「電気系設計側では信号ごとの対応までは確認していない」とされている PA6/PA7/PB4/PB5 と PC8/PC9/PB6/PB7 は、**電気系設計の基板にも同名ピンがある**。同じ配線なのか別かを回路図で確認する。
- エンコーダの A相/B相の割り当て（PC9=A, PC8=B など）が実際の回転方向と合っているか、実機で確認する。
- ブザー（UDB-05LFPN）がアクティブかパッシブか、データシートで確認する。
- ERR-03（バッテリー電圧監視）に使えるA/Dピンがなくなった（PC0〜3 は超音波Echo）。ADC対応の空きピン（PA1, PA4, PB0, PB1, PC5 など）に分圧回路を追加する必要がある。
- 液晶（MSP2807）の駆動ICと表示ライブラリ。
- 3.3Vの供給能力（A/D、I2C、変換モジュール、モータドライバ、液晶LEDが共用）。

| 設定 | 値 |

| TIM3 | CH1=PB4, CH2=PB5 を PWM Generation |
| TIM13 / TIM14 | CH1 を PWM Generation（PA6 / PA7） |
| TIM4 | Combined Channels: Encoder Mode（PB6, PB7、Period=65535） |
| TIM5 | Clock Source: Internal、Prescaler=83（84MHz時）、Period=0xFFFFFFFF |
| SPI2 | Transmit Only Master、CS(PB12) は GPIO出力 |
| USART2 | Asynchronous、115200bps、8N1 |
| GPIO出力 | PC10, PC11, PC12, PC4（Trig）、PA8, PA9（液晶）、PA0（ブザー）、PB14（LED D1） |
| GPIO入力 | PC13（開始/停止）、プルアップは外付け |
| GPIO EXTI | PC0〜PC3（Echo、両エッジ）、PC8, PC9（エンコーダ1、両エッジ） |
