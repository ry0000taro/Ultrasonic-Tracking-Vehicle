## 1. 目的・背景

人を追従し、荷物運搬のサポートをする移動台車を開発する（制作物コンセプト、仕様書xlsxより）。
超音波センサで対象物との距離を取得し、設定距離を保って追従・停止する制御をソフトウェアで実現する。

## 2. スコープ

- 対象: 移動台車の追従・停止・状態表示・安全停止に関わる**ソフトウェア（制御ロジック）**
- 含む: 距離計測処理、追従/停止判定、状態管理、LED表示制御、ブザー制御、走行制御（速度・位置決め）

### 2.1 スコープ外

- 機械設計・回路設計そのもの（別チーム／別文書で扱う。本書はソフトの制御ロジックのみを対象とする）
- 操作用UI・アプリ（PC/スマホ等からの遠隔操作・設定画面）は今回実装しない。内部定数／スイッチのみで完結する
  - ただし将来的にUIを追加する可能性はあるため、**将来拡張候補**として認識しておく（設計時に拡張しやすい形にしておくことが望ましい）
- 通信仕様の詳細（無線／ネットワーク）：Wi-Fi/Bluetooth等のリモート通信機能は今回の要件に含めず、スタンドアロンで動作する前提とする

### 2.2 スコープ未確定（TBD）

- 複数人同時追従・人物認識：現時点では対象外の想定に近いが、正式決定はTBD（今後検討）

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| 追従中 | 対象物を検知し、設定距離を保つよう走行制御している状態 |
| 停止中 | 近接停止または見失い停止により、意図して停止している状態 |
| エラー | センサ異常・モータ／駆動系異常・バッテリー電圧低下・障害物検知のいずれかを検知した状態（詳細は6章） |
| 見失う | 利用者（対象物）をソフトで設定した秒数以上、超音波センサで検知できない状態（秒数はTBD、7章参照） |
| 近接停止 | 対象物との距離が設定した閾値以内になったことによる停止 |

## 4. 制約条件

| ID | 内容 |
|---|---|
| CON-01 | 演習で支給されるDCモータ・エンコーダを使用すること（支給品以外のアクチュエータ／センサの追加は可） |
| CON-02 | バッテリーで動作可能なこと（外部電源前提としない） |
| CON-03 | 評価環境は平坦な屋内（研究実験棟2）の床、および作業用デスクの上 |
| CON-04 | 汚泥等の防汚要求は想定しない |
| CON-05 | 外形寸法 400×400 (W×D) mm 以下、重量 3.00 kg 以下 |
| CON-06 | 車輪配置は前方2箇所・後方1箇所（3輪構成） |

## 5. 機能要件（Functional Requirements）

各要件に仕様書xlsxの`実証方法`列を受け入れ基準として紐づける。

| ID | 要件 | 受け入れ基準／検証方法 | 優先度 |
|---|---|---|---|
| FR-01 | 超音波センサで対象物までの距離を継続的に取得できること | 実機検証 | Must |
| FR-02 | 複数センサ（前面配置）からの距離情報を扱えること | 実機検証 | Must |
| FR-03 | 検知した対象物との距離が設定した追従距離を保つよう走行制御（前進・後進・旋回・停止）すること | 実機検証 | Must |
| FR-04 | 追従距離をソフトウェア側で設定変更可能にすること | 実機検証 | Must |
| FR-05 | 対象物との距離が設定閾値以内になったら停止すること（近接停止） | 実機検証 | Must |
| FR-06 | 対象物を設定秒数以上検知できなかったら停止すること（見失い停止） | 実機検証 | Must |
| FR-07 | 台車の状態を「追従中／停止中／エラー」で管理し、他機能から参照可能にすること | 実機検証 | Must |
| FR-08 | 状態をLED板に色と文字で表示すること（追従中=緑「追従中」／停止中=黄「停止中」／エラー=赤「エラー」） | 実機検証 | Must |
| FR-09 | 対象物を見失った時・障害物検知時にブザーを鳴らすこと | 実機検証 | Must |
| FR-10 | エラー発生時にブザーで状況を知らせること | 実機検証 | Must |
| FR-11 | 前進・後進・旋回・停止の基本動作を制御できること | 実機検証 | Must |
| FR-12 | 指定した移動速度に設定でき、設定速度精度（NFR-02）を満たすこと | 実機検証 | Must |
| FR-13 | 指定された直進距離を自動走行し、位置精度（NFR-03）を満たして停止できること | 実機検証 | Must |
| FR-14 | 作業用デスク（1班分）の上で周回して指定位置に戻れること | 実機検証 | Must |
| FR-15 | 電気的／ソフト的スイッチにより動作開始／停止を制御できること（安全停止） | 実機検証 | Must |
| FR-16 | 規定の最大積載重量を搭載した状態でも、最大速度での動作が可能なこと | 規定重量を載せて走行確認 | Must |

### 8.1 IF-01 補足：サンプリング方式（提案・承認待ち）

超音波センサ4個を同時発火すると相互干渉（クロストーク）が生じるため、逐次（ラウンドロビン）発火とする。

| 項目 | 内容 | ステータス |
|---|---|---|
| 発火方式 | 逐次発火（同時発火不可） | 確定 |
| 発火順序（提案） | 前1 → 前2 → 左 → 前1 → 前2 → 右 → (繰返し) | 提案中・承認待ち |
| 周期（提案） | 前方センサ 約60ms／左右センサ 約120ms（1回の測距に約30ms確保: Trigger 10µs＋Echoタイムアウト上限〜25ms） | 提案中・承認待ち |
| 根拠 | 最大速度0.5m/sでは120ms周期でも移動量は約60mmに収まり、追従制御上問題ないと判断。追従制御の主軸である前方センサを優先的に更新する | - |
