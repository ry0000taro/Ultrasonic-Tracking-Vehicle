### 5.1 周回（R13）で決める値

| 値 | 何に使うか | 決め方（案） |
|---|---|---|
| デスクの寸法（W×D） | 経路の大きさ | 指定しない。経路の辺の長さを設定変数にして、評価の場で実際のデスクに合わせて入力する（D-13） |
| 経路の形 | 直進と旋回の順序 | 長方形を1周する（直進→90°旋回を4回繰り返す） |
| 出発位置と向き | 戻る場所の基準 | デスクの角の近くで、辺に沿った向き |
| 戻りの許容誤差（位置・向き） | 合格基準 | 仕様に記載なし。実機で計測して決める（D-13） |
| 縁からの余裕 | 机の縁から車体を離しておく最小の距離 | 実機で計測した最大のずれ（直進の横ずれ、旋回角の誤差、停止位置のずれ）の2倍を目安にする。初期値は仮に100mm。設定変数 `EDGE_MARGIN_MM` にする |
| 各辺の長さ | 直進距離 | デスク寸法 − 2×（旋回時の車体の張り出し＋余裕）。旋回時の張り出しは、400×400mmの車体を中心でその場旋回すると、最大で約283mm（対角の半分） |
| トレッド | 旋回角の計算 | 左右の駆動輪の、地面に接する面の中心どうしの距離（車軸方向）。ものさしで測り、10回転の試験で補正する。90°旋回で各輪が進む距離は π×トレッド÷4 |
| 旋回方式 | 旋回の動き | その場旋回（左右を逆回転）案 |
| 旋回の補正係数 | 経路のずれの抑制 | 角度1°の誤差は、1m進むと約17mmのずれになる。実走で補正係数を求める |
| 走行速度、旋回速度、加減速 | 周回中の動き | 走行速度は R28 の設定変数に合わせる。旋回は低速、加速度は0.3m/s²以内 |
| 周回数と最後の停止 | 終了条件 | 1周して出発位置で停止する |
| 障害物が来たとき | 安全 | 障害物検知は有効（停止し、離れたら再開） |
| mm_per_count | 距離の換算 | エンコーダの取り付け位置（D-08）が決まってから |
